git log mostra o histórico completo. git log --oneline mostra o histórico resumido, uma linha por commit. git diff mostra as diferenças ainda não preparadas. git show exibe os detalhes de um commit específico. Criando e trocando de branch git branch lista as branches existentes. git switch nome-da-branch troca para uma branch existente. git switch -c nome-da-branch cria e já entra na nova branch. git checkout -b nome-da-branch faz o mesmo, na sintaxe antiga. Merge Estando na branch de destino: git switch main git merge feature-login Comandos essenciais git clone URL baixa um repositório existente. git remote -v lista os remotos configurados. git remote add origin URL conecta seu repositório local a um remoto. git push origin main envia seus commits. git fetch baixa as novidades sem alterar seus arquivos. git pull baixa e já integra as novidades na sua branch. Desfazendo com segurança .gitignore lista arquivos que o Git deve ignorar, como node_modules e arquivos .env. git restore arquivo descarta alterações locais de um arquivo. git revert commit cria um novo commit que desfaz outro, preservando o histórico. git reset move o ponteiro do histórico e pode apagar commits. Tags e boas práticas Tags marcam versões importantes: git tag -a v1.0.0 -m "Primeira versão"
